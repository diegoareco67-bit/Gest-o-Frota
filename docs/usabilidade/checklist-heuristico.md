# Checklist Heurístico — FrotaGov

Avaliação baseada nas **10 Heurísticas de Nielsen**.  
Use a escala: ✅ OK · ⚠️ Problema leve · ❌ Problema grave · — Não se aplica

---

## H1 — Visibilidade do estado do sistema
*O sistema informa o usuário sobre o que está acontecendo.*

| # | Critério | Status | Observação |
|---|----------|--------|------------|
| 1.1 | Há indicador de carregamento ao buscar dados | | |
| 1.2 | Mensagem clara de sucesso após enviar solicitação | | |
| 1.3 | Status da solicitação é visível (Pendente / Aprovada / Recusada) | | |
| 1.4 | Botão de envio muda de estado enquanto processa ("Enviando...") | | |
| 1.5 | Usuário sabe em qual página está (item ativo na sidebar) | | |

---

## H2 — Correspondência entre sistema e mundo real
*A linguagem e os conceitos refletem a realidade do usuário.*

| # | Critério | Status | Observação |
|---|----------|--------|------------|
| 2.1 | Termos usados são familiares ao servidor público (ex: "solicitar", "aprovação") | | |
| 2.2 | Datas e formatos seguem o padrão brasileiro (dd/mm/aaaa) | | |
| 2.3 | Ícones e símbolos são reconhecíveis no contexto (✓ = aprovar, ✗ = recusar) | | |
| 2.4 | Nome das seções corresponde ao que o usuário esperaria encontrar | | |

| # | Critério | Status | Observação |

## H4 — Consistência e padrões

| # | Critério | Status | Observação |
|---|----------|--------|------------|
| 4.1 | Botões primários têm cor e estilo consistentes | | |

| # | Critério | Status | Observação |
