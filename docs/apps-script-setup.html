Hub CGE-MS · Fase 2 · Indenização de Transporte

Configurar o Google Apps Script Web App

O plano Firebase Spark não permite Cloud Functions. Esse Apps Script substitui o backend: recebe a URL de um PDF já salvo no Storage e a metadados da viagem, busca o arquivo e envia por e-mail com o PDF anexado para o RH/Contabilidade.

Antes de começar: faça login em script.google.com com a conta institucional da CGE-MS — nunca um Gmail pessoal. É essa conta que vai aparecer como remetente dos e-mails de indenização.
1

Criar o projeto

Abra script.google.com, já logado na conta institucional, e clique em Novo projeto.

Renomeie para algo reconhecível, ex.: "Hub CGE-MS — Envio de Indenização".

2

Colar o código

Apague o conteúdo padrão de Code.gs e cole isto — o e-mail do destinatário já está preenchido (suad@cge.ms.gov.br):

function doPost(e) {
  try {
    const dados = JSON.parse(e.postData.contents);
    const { urlArquivo, nomeServidor, matricula, destino, protocolo } = dados;

    // Busca o PDF que o cliente já salvou no Firebase Storage
    const resposta = UrlFetchApp.fetch(urlArquivo);
    const pdfBlob = resposta.getBlob().setName(
      `Indenizacao_${protocolo || matricula}.pdf`
    );

    MailApp.sendEmail({
      to: "suad@cge.ms.gov.br",
      subject: `Indenização de Transporte — ${nomeServidor} (${protocolo || matricula})`,
      body: `Segue em anexo o Boletim Demonstrativo de Viagem homologado.

Servidor: ${nomeServidor}
Matrícula: ${matricula}
Destino: ${destino}`,
      attachments: [pdfBlob],
    });

    return ContentService
      .createTextOutput(JSON.stringify({ ok: true }))
      .setMimeType(ContentService.MimeType.JSON);

  } catch (err) {
    return ContentService
      .createTextOutput(JSON.stringify({ ok: false, erro: err.message }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

Salve com Ctrl+S (ou Cmd+S).

3

Implantar como Web App

Clique em Implantar → Nova implantação. No tipo, escolha Aplicativo da Web.

Configure exatamente assim:

Executar como: Eu (a conta institucional logada)

Quem tem acesso: Qualquer pessoa

"Qualquer pessoa" é necessário pro app web chamar o script sem exigir login Google do servidor — mas ninguém descobre a URL por acaso, e o script só faz uma coisa (enviar e-mail), então o risco é baixo. Ainda assim, não divulgue a URL fora do código do projeto.
4

Autorizar

Clique em Implantar. O Google vai pedir autorização — escolha a conta institucional, clique em Avançado se aparecer aviso de app não verificado, e aceite o escopo de enviar e-mail em seu nome.

Esse aviso aparece porque é um script seu, não publicado na Play Store — é esperado, não é um problema de segurança.

5

Copiar a URL

Depois de implantado, copie a URL do app da Web (termina em /exec). Essa é a URL que o Hub vai chamar para disparar o e-mail.

6

Testar

Cole isto no terminal, trocando a URL pela sua e usando qualquer PDF público de teste como urlArquivo:

curl -X POST "SUA_URL_AQUI/exec" \
  -H "Content-Type: application/json" \
  -d '{"urlArquivo":"https://exemplo.com/teste.pdf","nomeServidor":"Teste","matricula":"000","destino":"Teste","protocolo":"TESTE001"}'

Se a resposta for {"ok":true} e o e-mail chegar com o anexo, está funcionando.

O que me mandar de volta

Assim que terminar, é só colar aqui na conversa:

  • A URL do Web App (a que termina em /exec)
  • Confirmação de que o teste do passo 6 funcionou (ou o erro, se não funcionou)
